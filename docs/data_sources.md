# Enterprise Data Sources

## PostgreSQL

Purpose:

Operational and serving-layer transaction data.

Examples:

- transaction lookup
- customer transactions
- transaction status
- revenue queries
- product analytics

---

## AWS S3

Purpose:

Historical enterprise data lake.

Layers:

Bronze
Silver
Gold

Used for:

- historical analytics
- batch processing
- model training
- reporting

---

## Vector Database

Purpose:

Enterprise unstructured knowledge.

Examples:

- refund policies
- company procedures
- product documentation
- customer support documents

---

## Redis

Purpose:

Fast temporary application state.

Examples:

- chat sessions
- conversation context
- agent checkpoints
- caching
